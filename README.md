# rootforclaude

Gradyan temalı "Başlıyoruz" sayfası — GitHub Pages ile yayınlanır.

## Yayınlama

1. Depoda **Settings → Pages** bölümüne gidin.
2. **Source** olarak "Deploy from a branch" seçin.
3. Branch olarak `index.html` dosyasının bulunduğu dalı ve `/ (root)` klasörünü seçip kaydedin.
4. Birkaç dakika içinde sayfa `https://rootkens.github.io/rootforclaude/` adresinde yayında olur.
